# CICIoT2023 cleaned data

Generated by `scripts/clean_ciciot2023.py` from `Merged01.csv, Merged02.csv`.
Output: `ciciot2023_clean.parquet` (918,764 rows, 37 features + `Label`, `family`, `is_attack`).

Load with `pd.read_parquet("data/CICIoT2023/clean/ciciot2023_clean.parquet")`.

## Cleaning steps

| Step | Rows | Removed |
|---|---:|---:|
| raw rows | 1,460,896 |  |
| after dropping NaN/inf rows | 1,460,869 | 27 |
| after dropping exact duplicate rows | 1,014,164 | 446,705 |
| after dropping ambiguous-label rows | 918,764 | 95,400 |

- NaN/inf: `Std` and `Variance` had NaN, `Rate` had inf.
- Ambiguous labels: rows whose 39 feature values are identical but whose `Label` differs. Almost all are
  DDoS vs DoS floods of the same protocol (e.g. `DDOS-TCP_FLOOD` vs `DOS-TCP_FLOOD`); a handful are
  BENIGN vs an attack. All copies of such vectors are removed, so every remaining feature vector has
  exactly one label and appears exactly once (no identical rows can land in both train and test).
- Dropped redundant columns: `Tot size` (== `AVG`), `LLC` (== `IPv`).
- Not done here: scaling, sampling, train/test split, device partitioning.
